Demo Quickstart (Google Sheets)

ThermaShift AI reads constraints and shift inputs from a Google Sheet, writes results back to the same Google Sheet, and emails an executive summary to the requesting operator.

~2-3 min
How to run the demo
  1. Click Open Google Sheet (this is the live demo control plane).
  2. (Optional) In the Google Sheet, apply one “Try this” change below.
  3. Enter your email and click Run Autonomous Dispatch Audit.
  4. Wait ~60–90 seconds, then check the Google Sheet + your inbox.
Dynamic Operating Policies (sheet-driven operating bounds)

What it does: The engine queries the Google Sheet tab Operating_Policy for operating bounds (Operating_Day_Start, Operating_Day_End) rather than using hardcoded hours.

Demo setup: Keep the Operating_Policy tab visible and editable.

Try this: In the Google Sheet, change Operating_Day_End from 22:00 to 14:00, then run an audit.

Expected: Proposed schedules respect the updated operating window (business constraints enforced by the sheet).

Calendar Deconfliction & Partial Shifts

What it does: The code isolates overlapping shifts at identical locations and falls back to safe partial-shift windows if a full shift exceeds heat bounds.

Try this: In the Google Sheet tab Audit_Queue, include sample rows with overlapping times at the same location, plus an 8-hour shift that overlaps peak heat (12:00–16:00) — e.g. 08:00–16:00 or 10:00–18:00.

Expected: Status updates show conflicts avoided and proposed window shifts, including partial shifts when no full safe block exists.

Error Architecture (failure isolation)

What it does: ThermaShift isolates operator-facing delivery from incident handling. Executive summaries are dynamically addressed to the requesting operator (the email you enter).

Expected: Uncaught pipeline crashes (external API outages, invalid schema corruption) trigger an asynchronous incident alert routed directly to operations engineering via the dedicated Error Trigger workflow.
